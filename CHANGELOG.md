# Changelog

## 0.1.1 — 2026-10-06

- Текст основной кнопки теперь принудительно отрисовывается белым в статическом, отключённом и динамическом состояниях.
- Устранено чёрное отображение надписи на тёмном и сером фоне кнопки.

## 0.1.0 — 2026-10-06

- Исправлена читаемость текста основной кнопки во всех состояниях, включая отключённое и активную обработку.
- Добавлен источник «С сайта»: загрузка товаров по артикулам из YML-каталога OutmaxShop.
- Добавлен импорт артикулов из `.txt`, `.doc` и `.docx`, совместимый с PARSER-MAX-2.
- Скачанные фотографии автоматически раскладываются по папкам артикула и передаются в существующий конвейер кадрирования.
- Добавлен оформленный TXT-отчёт для менеджера с эмодзи, сводкой и точными причинами пропусков/ошибок.
- Добавлен быстрый переход к отчёту из интерфейса после завершения очереди.

## 0.0.2 — 2026-10-06

- Исправлено распознавание крупных кадров, где тёмная обувь закрывает почти всю рамку изображения.
- Цвет студийного фона теперь оценивается по светлым участкам границы, а не по медиане всей границы.
- Добавлена регрессионная проверка дополнительных примеров крупняка для обоих форматов.

## 0.0.1 — 2026-10-06

- Первый публичный релиз WB Dropp.
- Drag & drop папок с товарными фотографиями.
- Автоматический выбор одного из четырёх Photoshop droplets по размеру и композиции кадра.
- Поддержка форматов 1400×1050 и Legacy 1000×750.
- Автоопределение крупных кадров, где товар выходит за границы изображения.
- Два режима сохранения: замена исходников или отдельная выходная папка.
- Очередь обработки, прогресс паков, отмена и локальный журнал ошибок.
- Self-contained сборка Windows x64.
