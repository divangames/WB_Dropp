# WB Dropp

WB Dropp — Windows-приложение для загрузки и автоматической маршрутизации товарных фотографий в Photoshop droplets. Источником могут быть готовые папки либо артикулы из каталога OutmaxShop.

## Правила обработки

| Исходник | Обычный кадр | Крупный кадр |
| --- | --- | --- |
| 1400×1050 | `Кадрирование.exe` | `Кадрирование_крупняк.exe` |
| 1000×750 | `Legacy_Кадрирование.exe` | `Legacy_Кадрирование_крупняк.exe` |

Крупный кадр определяется по содержимому: товар занимает заметную часть изображения и касается минимум двух границ. Другие размеры помечаются как «пропуск» и не передаются Photoshop.

## Возможности

- Два источника: drag & drop готовых папок или загрузка товаров по артикулам с сайта.
- Ввод артикулов вручную и импорт списков `.txt`, `.doc`, `.docx`.
- Совместимая с PARSER-MAX-2 структура: папка артикула, суффикс `_legacy`, названия фото и файл с размерами.
- Рекурсивное сканирование вложенных папок.
- Сводка по каждому паку: формат, количество крупных кадров и пропущенных файлов.
- Замена исходников или сохранение копий в отдельную папку с исходной структурой.
- Последовательная очередь с ожиданием фактического сохранения Photoshop.
- Понятный TXT-отчёт для менеджера с эмодзи, сводкой и причиной каждого пропуска.
- Отмена очереди после текущего файла и технический журнал ошибок в `%LOCALAPPDATA%\WBDropp\logs`.
- Самодостаточная сборка `win-x64`: пользователю не нужно устанавливать .NET.

## Загрузка с сайта

Переключитесь на «С сайта», вставьте артикулы или импортируйте файл и выберите папку загрузки. Программа читает YML-каталог OutmaxShop, скачивает до четырёх фотографий одновременно, создаёт папку `{артикул}` или `{артикул}_legacy`, а затем сразу запускает кадрирование.

Если артикул отсутствует, в карточке нет фотографий, сервер не отдал файл либо размер изображения не поддерживается, позиция не теряется молча: точная причина записывается в отчёт.

## Отчёт для менеджера

После каждой очереди создаётся файл `WB_Dropp_отчёт_для_менеджера_*.txt`. Он открывается обычным Блокнотом и содержит:

- общую сводку по готовым, частично готовым и пропущенным позициям;
- результат загрузки и кадрирования каждого артикула;
- количество кадров «крупняк» и неподдерживаемых размеров;
- понятную причину пропуска или ошибки.

В режиме «С сайта» отчёт лежит в подпапке `Отчёты WB Dropp` внутри папки загрузки. При сохранении «В папку» — внутри выбранной папки результата. В остальных случаях — в `Документы\WB Dropp\Отчёты`.

## Требования

- Windows 10/11 x64.
- Подключение к интернету для режима «С сайта».
- Adobe Photoshop, совместимый с приложенными droplets. Проверено с Photoshop 2026.
- Для разработки: .NET 8 SDK.

Photoshop можно не запускать заранее: первый droplet попробует открыть его автоматически. Во время обработки не закрывайте Photoshop и его диалоговые окна.

## Запуск и сборка

- `run.bat` — запуск из исходников.
- `build.bat` — проверка и Release-сборка.
- `publish.bat` — self-contained публикация и ZIP в `dist`.
- `release.bat "текст коммита"` — сборка, commit, push и GitHub Release текущей версии.

## Структура релиза

```text
WB Dropp.exe
droplers/
  Кадрирование.exe
  Кадрирование_крупняк.exe
  Legacy_Кадрирование.exe
  Legacy_Кадрирование_крупняк.exe
```

Droplets должны лежать рядом с приложением именно в папке `droplers`.

## Безопасность исходников

Режим «Заменить» намеренно передаёт исходные файлы в Photoshop и перезаписывает их. Для первой проверки используйте режим «В папку»: WB Dropp сначала копирует фото, затем обрабатывает копию.
