# WB Dropp

WB Dropp — Windows-приложение для автоматической маршрутизации товарных фотографий в Photoshop droplets. Перетащите одну или несколько папок с товарами, выберите способ сохранения и запустите очередь.

## Правила обработки

| Исходник | Обычный кадр | Крупный кадр |
| --- | --- | --- |
| 1400×1050 | `Кадрирование.exe` | `Кадрирование_крупняк.exe` |
| 1000×750 | `Legacy_Кадрирование.exe` | `Legacy_Кадрирование_крупняк.exe` |

Крупный кадр определяется по содержимому: товар занимает заметную часть изображения и касается минимум двух границ. Другие размеры помечаются как «пропуск» и не передаются Photoshop.

## Возможности

- Drag & drop сразу нескольких папок.
- Рекурсивное сканирование вложенных папок.
- Сводка по каждому паку: формат, количество крупных кадров и пропущенных файлов.
- Замена исходников или сохранение копий в отдельную папку с исходной структурой.
- Последовательная очередь с ожиданием фактического сохранения Photoshop.
- Отмена очереди после текущего файла и журнал ошибок в `%LOCALAPPDATA%\WBDropp\logs`.
- Самодостаточная сборка `win-x64`: пользователю не нужно устанавливать .NET.

## Требования

- Windows 10/11 x64.
- Adobe Photoshop, совместимый с приложенными droplets. Проверено с Photoshop 2026.
- Для разработки: .NET 8 SDK.

Photoshop можно не запускать заранее: первый droplet попробует открыть его автоматически. Во время обработки не закрывайте Photoshop и его диалоговые окна.

## Запуск и сборка

- `run.bat` — запуск из исходников.
- `build.bat` — проверка и Release-сборка.
- `publish.bat` — self-contained публикация и ZIP в `dist`.
- `release.bat "текст коммита"` — сборка, commit, push и GitHub Release `v0.0.1`.

## Структура релиза

```text
WB Dropp.exe
droplers/
  Кадрирование.exe
  Кадрирование_крупняк.exe
  Legacy_Кадрирование.exe
  Legacy_Кадрирование_крупняк.exe
```

Droplets должны лежать рядом с приложением именно в папке `droplers`.

## Безопасность исходников

Режим «Заменить» намеренно передаёт исходные файлы в Photoshop и перезаписывает их. Для первой проверки используйте режим «В папку»: WB Dropp сначала копирует фото, затем обрабатывает копию.
